Typing Configuration

How text is typed into Instagram — both the login form and the Campaign's messages. Speed and Jitter add up per keystroke, and Corrections adds extra keystrokes, so all three decide how long a message takes to write.

🖱 Scrolling

How Scrapping scrolls the home feed while collecting usernames. Nothing to do with typing — a shorter pause and a bigger step both make it faster, but a bigger step skips more posts. The same values as Scrapping → ⚙️ Settings; changing them here changes them there.

📣 Campaign batching

Run each account’s list in random-sized batches with a random minute delay between them, instead of one long burst. The next-batch countdown shows in 📊 Campaign view.

🧭 Panels

Enable or disable the buttons in the top navigation. Untick a panel to disable its button — it stays visible but is greyed out and can’t be clicked; tick it to enable it again. Config can’t be disabled — it’s how you reach these switches. Applies immediately and is remembered in this browser (not part of Save).
